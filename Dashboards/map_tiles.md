## Map Tiles

**The URL for Google Maps tiles is:**  
http://mt.google.com/vt/lyrs=m&x={x}&y={y}&z={z}

**Max Zoom Level:** 22

### LYRS
**H** = Roads Only  
**M** = Standard Roadmap  
**P** = Terrain  
**R** = Somehow Altered Roadmap  
**S** = Satellite Only  
**T** = Terrain Only  
**Y** = Hybrid
